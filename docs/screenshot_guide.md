# คู่มือถ่ายภาพหน้าจอสำหรับส่งงาน (Screenshot guide)

ถ่ายภาพจาก **แอปที่ deploy บน Streamlit Community Cloud แล้ว** (ไม่ใช่ localhost) เพื่อยืนยันว่าแอปใช้งานได้จริง ใช้หน้าต่างเบราว์เซอร์กว้างประมาณ 1400 px ให้เห็นทั้ง sidebar และพื้นที่แชต

บันทึกไฟล์ลงโฟลเดอร์ `screenshots/` ตามชื่อด้านล่าง แล้วคัดลอก `screenshots/captions.example.json` เป็น `screenshots/captions.json` และแก้คำอธิบายให้ตรงกับภาพจริง (เช่น URL แอป, คำตอบที่ได้) จากนั้นรัน:

```bash
python make_screenshot_pdf.py      # ได้ screenshots.pdf (+ screenshots.html สำรองสำหรับ Print → Save as PDF)
```

## รายการภาพที่ต้องถ่าย

### 1. หน้าแรก (Home page) — `01_home.png`
- **ถ่ายอะไร:** เปิดแอปครั้งแรก ให้เห็นชื่อแอป ข้อความต้อนรับ การ์ดคำถามตัวอย่าง 6 ใบ (จัดกลุ่ม ข้าว / ทุเรียน / วินิจฉัยอาการ / ความปลอดภัย) และ sidebar ทั้งหมด พร้อม URL `*.streamlit.app` ในแถบที่อยู่
- **คำอธิบาย (template):**
  > หน้าแรกของแอป "ผู้ช่วยด้านการเกษตรและโรคพืช" ที่ deploy บน Streamlit Community Cloud (URL: `https://<your-app>.streamlit.app`) แสดงข้อความต้อนรับและการ์ดคำถามตัวอย่างที่จัดกลุ่มตามหัวข้อ คลิกเพื่อถามได้ทันที ด้านซ้ายเป็น sidebar ที่มีคำอธิบายแอป การตั้งค่า รายการหัวข้อในคลังความรู้ และปุ่มล้างการสนทนา

### 2. คำถามภาษาไทยพร้อมเปิดแหล่งข้อมูล — `02_thai_question_sources.png`
- **ถ่ายอะไร:** คลิกการ์ด `โรคไหม้ข้าวมีอาการอย่างไร และป้องกันได้อย่างไร` แล้ว **คลิกเปิด "แหล่งข้อมูล (N)"** ให้เห็นทั้งคำตอบ (ป้าย citation ตัวยก 1, 2, ...) และการ์ดแหล่งข้อมูล (เลขลำดับ ชื่อเอกสาร หัวข้อ แถบความเกี่ยวข้อง ข้อความตัวอย่างที่ไฮไลต์) อาจต้องถ่าย 2 ภาพหรือ zoom out
- **คำอธิบาย (template):**
  > ผู้ใช้ถามเป็นภาษาไทย ระบบค้นคืน chunk ที่เกี่ยวข้องจาก FAISS แล้วให้ LLM (Groq) ตอบตามเอกสารเท่านั้น คำตอบมีโครงสร้าง อาการ → สาเหตุ → การป้องกัน และมีป้ายอ้างอิงตัวเลขที่ตรงกับการ์ดแหล่งข้อมูลด้านล่าง แต่ละการ์ดแสดงชื่อเอกสาร (ลิงก์ไปต้นฉบับ) หัวข้อ คะแนนความคล้าย และข้อความที่ตรงกับคำถาม ป้าย "อ้างอิงในคำตอบ" ระบุแหล่งที่ถูกใช้จริง หากคำตอบกล่าวถึงสารเคมี จะมีแถบเตือนขอบสีอำพันให้อ่านฉลาก

### 3. คำถามภาษาอังกฤษ — `03_english_question.png`
- **ถ่ายอะไร:** ถาม `How can I tell if my tomato plant has bacterial wilt?` (หรือ `How much water does durian need?` เพื่อโชว์การตอบข้ามภาษาจากเอกสารไทย)
- **คำอธิบาย (template):**
  > ผู้ใช้ถามเป็นภาษาอังกฤษ บอตตอบเป็นภาษาอังกฤษพร้อมอ้างอิง แสดงว่าโมเดล embedding หลายภาษา (multilingual-e5-small) ค้นคืนได้ทั้งเอกสารภาษาไทยและอังกฤษ และ LLM ตอบในภาษาเดียวกับคำถาม

### 4. การถามต่อเนื่อง (Multi-turn follow-up) — `04_follow_up.png`
- **ถ่ายอะไร:** ต่อจากภาพที่ 2 ถาม `แล้วโรคนี้ป้องกันยังไง` แล้วเปิด "แหล่งข้อมูล (N)" ให้เห็นบรรทัด **"คำค้นที่ใช้: วิธีป้องกันโรคไหม้ข้าว"**
- **คำอธิบาย (template):**
  > คำถามต่อเนื่องไม่ได้ระบุชื่อโรค ระบบใช้ประวัติการสนทนาให้ LLM เขียนคำถามใหม่เป็นคำค้นที่สมบูรณ์ ("วิธีป้องกันโรคไหม้ข้าว") ก่อนค้นหา จึงได้เอกสารที่ถูกต้องและตอบต่อเนื่องได้

### 5. คำถามที่ไม่มีในเอกสาร (No-information card) — `05_unanswerable.png`
- **ถ่ายอะไร:** ถาม `ราคาทุเรียนหมอนทองวันนี้เท่าไร` (หรือ `How do I control coffee leaf rust?`) ให้เห็นการ์ด **"ไม่พบข้อมูลในเอกสารที่มี"** ทั้งใบ: คำอธิบาย หัวข้อใกล้เคียง คำถามแนะนำ และคำแนะนำให้ติดต่อสำนักงานเกษตรอำเภอ
- **คำอธิบาย (template):**
  > เมื่อถามเรื่องที่ไม่มีในคลังความรู้ บอตไม่เดาคำตอบ แต่แสดงการ์ดที่สงบและเป็นกลาง (ไม่ใช่ข้อความ error) บอกว่าไม่พบข้อมูลในเอกสาร แสดงหัวข้อใกล้เคียงที่มีในคลังความรู้ และคำถามแนะนำที่คลิกถามต่อได้ ระบบตรวจจับได้ 2 ชั้น: คะแนนการค้นหาต่ำกว่าเกณฑ์ (ไม่เรียก LLM) หรือ LLM ตอบสัญญาณ `[[NO_INFO]]` ซึ่งทั้งสองแบบให้ผลลัพธ์ `status="no_info"` รูปแบบเดียวกัน

### 6. การตั้งค่าใน Sidebar — `06_sidebar_controls.png`
- **ถ่ายอะไร:** ปรับ slider top-k (เช่น เป็น 3) และเลือก "ภาษาของคำตอบ" แล้วถามคำถาม 1 ข้อ ให้เห็นว่าจำนวนใน "แหล่งข้อมูล (N)" เปลี่ยนตาม top-k พร้อมเห็นส่วน "คลังความรู้" ที่แสดงหัวข้อแยกตามพืชและจำนวนเอกสาร จากนั้น (ภาพเพิ่มเติม) กด "ล้างการสนทนา"
- **คำอธิบาย (template):**
  > Sidebar มีคำอธิบายแอป ตัวอย่างคำถาม การตั้งค่าจำนวนเอกสารที่ค้นคืน (top-k) และภาษาของคำตอบ รายการหัวข้อในคลังความรู้แยกตามพืช (พร้อมจำนวนเอกสารและจำนวน chunk) ปุ่มล้างการสนทนา และข้อจำกัดความรับผิดชอบ

### 7. เปิดในโหมดไม่ระบุตัวตน (Incognito) — `07_incognito.png`
- **ถ่ายอะไร:** เปิดลิงก์แอปในหน้าต่าง Incognito/Private (ให้เห็นสัญลักษณ์ incognito ของเบราว์เซอร์) แล้วถามคำถาม 1 ข้อให้ได้คำตอบ
- **คำอธิบาย (template):**
  > เปิดแอปในหน้าต่าง Incognito โดยไม่ได้ล็อกอิน แอปโหลดและตอบคำถามได้ตามปกติ แสดงว่าผู้ใช้ทั่วไปเข้าถึงได้ และ API key ถูกเก็บใน Streamlit Secrets ไม่ได้อยู่ในโค้ดหรือ repository

### 8. (ไม่บังคับ) มุมมองบนมือถือ — `08_mobile.png`
- **ถ่ายอะไร:** เปิดแอปบนมือถือ หรือใช้ DevTools โหมดอุปกรณ์ขนาด 390 px
- **คำอธิบาย (template):**
  > หน้าจอปรับตามขนาดมือถือ การ์ดคำถามเรียงเป็นคอลัมน์เดียว ไม่มีการเลื่อนแนวนอน และ sidebar ยุบเก็บได้

### เคล็ดลับ
- macOS: `Cmd + Shift + 4` (เลือกพื้นที่) หรือ `Cmd + Shift + 5`; Windows: `Win + Shift + S`
- ถ้าคำตอบยาว ให้ zoom out เบราว์เซอร์ (`Cmd/Ctrl + -`) เพื่อให้เห็นคำตอบและแหล่งข้อมูลในภาพเดียว
- อย่าให้ภาพหน้าจอติดหน้า **Settings → Secrets** ที่มี API key
