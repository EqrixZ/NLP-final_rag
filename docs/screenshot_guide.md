# คู่มือถ่ายภาพหน้าจอสำหรับส่งงาน (Screenshot guide)

ถ่ายภาพจาก **แอปที่ deploy บน Streamlit Community Cloud แล้ว** (ไม่ใช่ localhost) เพื่อยืนยันว่าแอปใช้งานได้จริง ใช้หน้าต่างเบราว์เซอร์กว้างประมาณ 1400 px ให้เห็นทั้ง sidebar และพื้นที่แชต

บันทึกไฟล์ลงโฟลเดอร์ `screenshots/` ตามชื่อด้านล่าง แล้วคัดลอก `screenshots/captions.example.json` → `screenshots/captions.json` แก้คำอธิบายให้ตรงกับภาพจริง (เช่น URL แอป, คำตอบที่ได้) จากนั้นรัน:

```bash
python make_screenshot_pdf.py      # → screenshots.pdf (+ screenshots.html สำรองสำหรับ Print → Save as PDF)
```

## รายการภาพที่ต้องถ่าย

### 1. หน้าแรก (Home page) — `01_home.png`
- **ถ่ายอะไร:** เปิดแอปครั้งแรก เห็นชื่อแอป ข้อความต้อนรับ และ sidebar ทั้งหมด ให้เห็น URL `*.streamlit.app` ในแถบที่อยู่
- **คำอธิบาย (template):**
  > หน้าแรกของแอป "ผู้ช่วยผู้เชี่ยวชาญด้านการเกษตรและโรคพืช" ที่ deploy บน Streamlit Community Cloud (URL: `https://<your-app>.streamlit.app`) แสดงข้อความต้อนรับ และ sidebar ที่มีคำอธิบายแอป ตัวอย่างคำถาม ตัวปรับ top-k ปุ่มล้างการสนทนา และข้อจำกัดความรับผิดชอบ

### 2. คำถามภาษาไทยพร้อมเปิดแหล่งข้อมูล — `02_thai_question_sources.png`
- **ถ่ายอะไร:** ถาม `โรคไหม้ข้าวมีอาการอย่างไร และป้องกันได้อย่างไร` แล้ว **คลิกเปิด expander "📚 แหล่งข้อมูลที่ค้นพบ"** ให้เห็นทั้งคำตอบ (มี `[1]`, `[2]`) และรายการ chunk (ชื่อเอกสาร › หัวข้อ, คะแนนความคล้าย, ไฟล์, เนื้อหา) อาจต้องถ่าย 2 ภาพหรือ zoom out
- **คำอธิบาย (template):**
  > ผู้ใช้ถามเป็นภาษาไทย ระบบค้นคืน chunk ที่เกี่ยวข้องจาก FAISS แล้วให้ LLM (Groq) ตอบตามเอกสารเท่านั้น คำตอบมีโครงสร้าง อาการ → สาเหตุ → การป้องกัน และอ้างอิง [1], [2] ซึ่งตรงกับรายการใน expander ที่แสดงชื่อเอกสาร หัวข้อ คะแนน cosine similarity และเนื้อหา chunk ✅ ระบุ chunk ที่ถูกอ้างอิงในคำตอบ

### 3. คำถามภาษาอังกฤษ — `03_english_question.png`
- **ถ่ายอะไร:** ถาม `How can I tell if my tomato plant has bacterial wilt?` (หรือ `How much water does durian need?` เพื่อโชว์การตอบข้ามภาษาจากเอกสารไทย)
- **คำอธิบาย (template):**
  > ผู้ใช้ถามเป็นภาษาอังกฤษ บอตตอบเป็นภาษาอังกฤษพร้อมอ้างอิง แสดงว่าโมเดล embedding หลายภาษา (multilingual-e5-small) ค้นคืนได้ทั้งเอกสารภาษาไทยและอังกฤษ และ LLM ตอบในภาษาเดียวกับคำถาม

### 4. การถามต่อเนื่อง (Multi-turn follow-up) — `04_follow_up.png`
- **ถ่ายอะไร:** ต่อจากภาพที่ 2 ถาม `แล้วโรคนี้ป้องกันยังไง` แล้วเปิด expander ให้เห็นบรรทัด **"🔎 คำค้นที่ใช้หลังเขียนคำถามใหม่ (query rewriting): …"**
- **คำอธิบาย (template):**
  > คำถามต่อเนื่องไม่ได้ระบุชื่อโรค ระบบใช้ประวัติการสนทนาให้ LLM เขียนคำถามใหม่เป็นคำค้นที่สมบูรณ์ ("วิธีป้องกันโรคไหม้ข้าว") ก่อนค้นหา จึงได้เอกสารที่ถูกต้องและตอบต่อเนื่องได้

### 5. คำถามที่ไม่มีในเอกสาร (Refusal) — `05_unanswerable.png`
- **ถ่ายอะไร:** ถาม `ราคาทุเรียนหมอนทองวันนี้เท่าไร` (หรือ `How do I control coffee leaf rust?`) ให้เห็นคำตอบ **"ไม่พบข้อมูลในเอกสารที่มี"**
- **คำอธิบาย (template):**
  > เมื่อถามเรื่องที่ไม่มีในคลังความรู้ บอตตอบด้วยข้อความปฏิเสธที่กำหนดไว้ "ไม่พบข้อมูลในเอกสารที่มี" แทนการเดาหรือแต่งคำตอบ ตามที่ system prompt บังคับไว้ (และหากไม่มี chunk ใดผ่าน threshold ระบบจะปฏิเสธทันทีโดยไม่เรียก LLM)

### 6. การตั้งค่าใน Sidebar — `06_sidebar_controls.png`
- **ถ่ายอะไร:** ปรับ slider top-k (เช่น เป็น 3) แล้วคลิกตัวอย่างคำถามข้อหนึ่ง ให้เห็นว่าคำถามถูกส่งทันทีและ expander แสดงจำนวนแหล่งข้อมูลตาม top-k; จากนั้น (ภาพเพิ่มเติม) กด "🗑️ ล้างการสนทนา"
- **คำอธิบาย (template):**
  > Sidebar มีตัวอย่างคำถามที่คลิกแล้วถามได้ทันที ตัวปรับจำนวนเอกสารที่ค้นคืน (top-k) และปุ่มล้างการสนทนา พร้อมแสดงชื่อโมเดลที่ใช้และข้อจำกัดความรับผิดชอบ

### 7. เปิดในโหมดไม่ระบุตัวตน (Incognito) — `07_incognito.png`
- **ถ่ายอะไร:** เปิดลิงก์แอปในหน้าต่าง Incognito/Private (ให้เห็นสัญลักษณ์ incognito ของเบราว์เซอร์) แล้วถามคำถาม 1 ข้อให้ได้คำตอบ
- **คำอธิบาย (template):**
  > เปิดแอปในหน้าต่าง Incognito โดยไม่ได้ล็อกอิน แอปโหลดและตอบคำถามได้ตามปกติ แสดงว่าผู้ใช้ทั่วไปเข้าถึงได้ และ API key ถูกเก็บใน Streamlit Secrets ไม่ได้อยู่ในโค้ดหรือ repository

### เคล็ดลับ
- macOS: `Cmd + Shift + 4` (เลือกพื้นที่) หรือ `Cmd + Shift + 5`; Windows: `Win + Shift + S`
- ถ้าคำตอบยาว ให้ zoom out เบราว์เซอร์ (`Cmd/Ctrl + -`) เพื่อให้เห็นคำตอบและแหล่งข้อมูลในภาพเดียว
- อย่าให้ภาพหน้าจอติดหน้า **Settings → Secrets** ที่มี API key
